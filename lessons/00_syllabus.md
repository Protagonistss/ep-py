# ep-py 教学大纲

> 本文件是整个课程的**唯一规划真源**:每课教什么、先教什么后教什么、哪里埋伏笔哪里回收,以此为准。
> 讲义和练习的编写规范见仓库根目录 [AGENTS.md](../AGENTS.md)。

---

## 1. 课程定位

| | |
| ---- | ---- |
| 面向人群 | 完全零基础的成年人(会开机、会用浏览器,没写过代码) |
| 课程形态 | 线下授课为主,每课 90 分钟,讲义 + 练习模板全部在仓库里 |
| 总课时 | 12 课(9 个关卡项目,其中"类"和"工程化"各拆两课,外加 1 课阶段实战) |
| 完课画像 | 能独立开发、测试、打包一个数百行的命令行小项目,遇到报错会自己定位 |

**不是目标**:覆盖 Python 全部语法;追求"背过多少 API"。一切语法都为了项目服务。

---

## 2. 教学原则(全局约束,每课讲义必须遵守)

1. **项目驱动**:每课先看到"今天做出什么",知识点只是顺手点亮的能力
2. **四步走**:每个新知识点按「是什么 → 为什么需要 → 怎么用 → 动手试」展开,不停留在"照着敲"
3. **讲练 1:1**:每个环节纯讲授 ≤ 5 分钟,学员动手时间不少于一半
4. **报错是教材**:每个环节至少安排一次"故意写错",让学员见过、不怕、会读
5. **埋点与回收**:难概念提前埋伏笔(当"魔盒"用),到指定课再揭原理;禁止提前掀盖子

## 4. 阶段划分与 Checkpoint

**阶段一 · 入门(第 1~2 课)**:顺序 → 分支 → 循环,建立"输入 → 处理 → 输出"模型
**阶段二 · 数据组织与函数(第 3~5 课)**:数据装进容器,代码装进函数
**阶段三 · 抽象与工程(第 6~9 课)**:从"写脚本"到"做工程":类、模块、文件、异常
**阶段四 · 进阶与工程化(第 10~12 课)**:语言进阶特性 + 让项目"正规"起来

| 关卡 | 验收标准(能独立做到才算过) |
| ---- | ---- |
| **CP1** 第 2 课后 | 不看讲义,从零写出完整猜数字(循环 + 分支 + 随机);读报错能说出类型、行号、原因 |
| **CP2** 第 5 课后 | 把 50 行以上的旧项目拆成函数;能脱稿讲清参数、返回值、作用域各解决什么问题 |
| **CP3** 第 9 课后 | 独立定义类;把单文件项目拆成多模块;读写 json 持久化数据;能对已知异常做兜底 |
| **CP4** 第 12 课后 | 结课项目:有类型注解、有 pytest 测试、`uv run` 一键启动;15 分钟现场演示 |

## 5. 逐课明细

### 第 1 课 · 🥚 你好,Python!——自我介绍生成器 ✅

- **新知识点**:print 与函数初印象 · 字符串与引号规则 · 变量与赋值 · 四大类型(str/int/float/bool)· `type()` · input(返回字符串)· 类型转换 · 算术运算符(`+ - * / // % **`)· 字符串 `+`/`*` · f-string(含 `:.1f`)
- **埋点**:bool 预告"第 2 课主角" · `int(input())` 的坑 · `%` 取余 · ValueError
- **作业**:温度转换器 / BMI 计算器 / 名字艺术字(三选二)
- 文件:`lessons/01_hello_python.md` · `exercises/01_basics/`

### 第 2 课 · 🐣 猜数字游戏 ✅

- **新知识点**:比较运算符(`== != > < >= <=`)· bool 表达式 · if/elif/else(冒号与缩进即语法)· while 三件套 · 死循环与 Ctrl+C · for 与 range(含头不含尾、步长)· break · `+=`/`-=` · `import random` 魔盒
- **回收**:bool 预告(环节①)· `int(input())` 的坑(课堂项目再踩一次)
- **埋点**:import 原理(→ 第 8 课)· ValueError 乱输入(→ 第 9 课)· 猜数字项目(→ 第 5 课重构、第 10 课装饰器改造)
- **作业**:奇偶判断器 / 乘法口诀生成器 / 密码锁(三选二)
- 文件:`lessons/02_guess_number.md` · `exercises/02_flow/`

### 第 3 课 · 🐥 命令行待办清单 ⏳

- **项目**:命令行菜单程序——添加/查看/标完成/删除待办,退出前打印今日小结
- **新知识点**:列表(CRUD · 索引与负索引 · 遍历)· `in` / `not in` · 字典(键值读写 · `.items()` 遍历)· 集合入门(去重、成员查找,深入用法后课随用随讲)· `sorted` / `min` / `max` / `sum`(作业里练统计)
- **复习/回收**:while True + break(菜单循环)· if/elif(菜单分发)· f-string(渲染)
- **作业方向**:购物清单 / 成绩单统计 / 单词收藏夹
- **难度**:★★☆☆☆(容器第一次登场,概念卡重点回答"为什么一个变量装不下")
- 文件(暂定):`lessons/03_todo_list.md` · `exercises/03_containers/`

### 第 4 课 · 🐤 单词测验闯关 ⏳

- **项目**:词库抽题 → 答题判分 → 闯关结算,全部逻辑装进函数
- **新知识点**:def 与调用 · 参数(位置/默认/关键字)· return 与返回值 · **None**(不写 return 时的默认返回)· **tuple**(多返回值与解包,“不可变的列表”一句话带过)· 字符串方法入门(`upper` / `lower` / `strip`,判卷规范化用)· 作用域(局部/全局,只讲够用的边界感)· 自顶向下拆任务的思路 · `random.choice` / `shuffle`(继续当魔盒)
- **复习/回收**:列表(词库)· 字典(计分)· 循环(答题轮)
- **作业方向**:把第 1 课温度/BMI 作业改造成函数版 / 掷骰子函数 / 自定义小 quiz
- **难度**:★★★☆☆(从"写脚本"到"组织代码"的第一次转身)
- 文件(暂定):`lessons/04_word_quiz.md` · `exercises/04_functions/`

### 第 5 课 · 🛠️ 阶段实战营 ⏳

- **项目**:用函数重构猜数字与待办清单;重构前先给旧代码"体检"
- **新知识点**:无新语法(可顺带预告 docstring)。目标:读懂一个月前的自己、独立拆函数、完成 CP2 口试自查清单
- **复习/回收**:第 1~4 课全部知识;埋点 docstring(→ 第 11 课类型注解与文档)
- **难度**:★★☆☆☆(难度刻意放低,要求独立完成)
- 文件(暂定):`lessons/05_review_camp.md` · `exercises/05_refactor/`

### 第 6 课 · 🐱 宠物养成小游戏(上) ⏳

- **项目**:定义宠物——名字、饥饿度、心情,能被喂食和玩耍
- **新知识点**:class 与实例 · `__init__` · 属性 · 实例方法与 self · 创建多个对象
- **切入**:从"三只猫三套变量"的麻烦讲起,回答"为什么需要类"
- **复习/回收**:函数(方法 = 绑在对象上的函数)· 字典(属性像键值)
- **难度**:★★★★☆(课程第一个大台阶,节奏放慢,环节拆小)
- 文件(暂定):`lessons/06_pet_game_a.md` · `exercises/06_classes/`

### 第 7 课 · 🐱 宠物养成小游戏(下) ⏳

- **项目**:继承出宠物种类(猫/狗/龙各有技能),接上回合主循环,游戏可玩
- **新知识点**:继承 · 方法重写 · super() 基础 · 用类组织游戏状态机(饥饿/心情随回合变化)
- **复习/回收**:while(回合循环)· random(随机事件)· 容器(背包)
- **难度**:★★★★☆
- 文件(暂定):`lessons/07_pet_game_b.md` · `exercises/07_inheritance/`

### 第 8 课 · 📂 批量文件整理脚本 ⏳

- **项目**:扫描指定文件夹,按扩展名把文件归类到子文件夹,输出整理报告
- **新知识点**:import 的原理(回收第 2 课 random 魔盒)· 标准库 vs 自写模块 · 多文件项目拆分(如 `todo.py` + `main.py`)· pathlib 路径与目录操作 · json 读写(存整理规则)
- **复习/回收**:待办清单项目(→ 拆成多模块)· 字典(规则映射)
- **埋点**:json(→ 第 9 课账本存储、第 12 课配置文件)
- **难度**:★★★☆☆(第一次操作真实文件系统,演示区隔"玩具代码"与"动真格的代码")
- 文件(暂定):`lessons/08_file_organizer.md` · `exercises/08_modules/`

### 第 9 课 · 📓 记账本 ⏳

- **项目**:记账(增/删/查/月度统计),账目持久化到 json,乱输入不再崩
- **新知识点**:open 与 with 读写 · try/except(含多 except、finally)· 常见异常类型 · 输入校验的正规写法 · `datetime.date.today()`(当标准库工具用,给账目记当天日期)
- **回收**:`int(input())` 坑 + ValueError(第 1、2 课埋,本课彻底收尾)
- **复习/回收**:json(第 8 课)· 字典(账目结构)· f-string(报表)
- **难度**:★★★☆☆
- 文件(暂定):`lessons/09_ledger.md` · `exercises/09_files_errors/`

### 第 10 课 · 🎩 给旧项目装上新能力 ⏳

- **项目**:记账本/猜数字 2.0——加分页报表、计时日志
- **新知识点**:for 的本质(iter/next)· 迭代器协议 · 生成器与 yield · 装饰器(@timer/@log)
- **回收**:猜数字项目(装饰器改造)· 函数(第 4 课是本课硬前置)
- **难度**:★★★★★(第二个大台阶;靠"给旧项目升级"的真实感压住抽象感)

### 第 11 课 · 🚀 工程化(上) ⏳

- **新知识点**:类型注解(变量与函数签名)· assert 与 pytest 第一个测试 · 测试函数的命名与结构 · `uv run pytest` · 参数化初步
- **复习/回收**:函数拆分(→ 拆得好才好测)· docstring(→ 和注解一起构成"函数说明书")
- **难度**:★★★☆☆(仓库 dev 依赖已内置 pytest,无需新增)

### 第 12 课 · 🚀 工程化(下)· 结课验收 ⏳

## 6. Python 类型覆盖一览

| 类型 | 首次登场 | 课程内的落点 |
| ---- | :--: | ---- |
| `str` 字符串 | 第 1 课 | 引号规则、`+`/`*`、f-string;`upper/lower/strip` 第 4 课判卷时用,`split/join` 第 8 课处理文件名时用 |
| `int` / `float` | 第 1 课 | 算术与 `/` `//`、类型转换、`:.1f` 格式化 |
| `bool` | 第 1 课(预告)→ 第 2 课(主角) | 比较表达式、分支与循环的"开关";第 5 课密码锁用 `opened` 记状态 |
| `list` 列表 | 第 3 课 | CRUD、索引、遍历;`sorted/min/max/sum` 作业里练 |
| `dict` 字典 | 第 3 课 | 键值读写、`.items()` 遍历;`.get` 第 9 课记账时顺带 |
| `set` 集合 | 第 3 课(入门) | 去重与成员查找;深入用法后课随用随讲 |
| `None` | 第 4 课 | "没有值"的唯一成员:函数不写 return 时的默认返回 |
| `tuple` 元组 | 第 4 课 | 多返回值与解包;不可变性一句话带过,不做展开 |
| 自定义类型(class) | 第 6~7 课 | 属性、方法、继承——学员自己造类型 |
| 类型注解 | 第 11 课 | `int` / `str` / `list[int]` / `dict[str, int]` 与 typing 初步 |
| `datetime.date` | 第 9 课 | 标准库工具性质:`date.today()` 记当天日期 |

**明确不讲**(教学原则:不追求穷举,教"遇到会查"):`bytes` / `complex` / `frozenset` / `bytearray` / `Decimal` 等;需要时在讲义里以"冷知识/拓展"形式出现。

## 8. 文件与命名规范

- 讲义:`lessons/NN_主题.md`(如 `03_todo_list.md`);大纲固定为 `lessons/00_syllabus.md`
- 练习:`exercises/NN_主题/`,含 1 个课堂项目模板 + ≥ 3 个作业模板 `homework_*.py`(学员三选二)
- 参考实现只写在讲义的折叠块里,**不进练习目录**(学员 `git pull` 只拿模板)
- 已发布课程(README 标 ✅)内容冻结:只允许修错(错别字、代码错误、坏链),不允许调整知识点

4. 提交信息示例:`新增第 3 课讲义与练习` / `大纲:调整第 8 课知识点`
