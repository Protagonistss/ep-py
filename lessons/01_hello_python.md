### 📘 概念卡 · print 与字符串

**是什么**
- `print(...)` 把括号里的内容打印到屏幕。它是我们的第一个**函数**:一台"小机器",递给它原料,它干一件事
- 引号包起来的一串文字,叫做**字符串**(`str`),上面的 `"你好,世界!"` 就是

**为什么文字要加引号**
- 引号是 Python 的"分界线":引号里面是**数据**(给人看的内容),引号外面是**代码**(给计算机执行的指令)
- 没有引号,Python 会把 `你好` 当成代码去执行——然后报错

**特性**
- 想知道一段文字有几个字符?用 `len()`:

```python
print(len("你好"))       # 2,一个汉字算一个字符
print(len("hello"))      # 5
```

- 字符串还有"重复、拼接"等特性,环节 ⑤ 会用到

## 环节 ③:变量与数据类型(20 min)

### 从一个麻烦说起

```python
print("大家好,我叫小明,今年 18 岁")
print("小明明年 19 岁")
print("小明的名字是三个字")
```

名字和年龄被写了三遍,要改名/改年龄,得改三处。**数据会被重复使用,就该给它起个名字**——这就是变量存在的理由。

> 📘 **概念卡 · 变量**
>
> **是什么**:变量 = 给数据贴的一个**名字标签**。`name = "小明"` 读作"把 `小明` 这个字符串存起来,贴上 `name` 的标签"。
>
> **为什么需要**:数据写第二次就要用变量;一处修改,处处生效。
>
> **特性**:
> - 里面的值**随时可以换**,所以才叫"变"量:`age = 18` 之后再来一句 `age = 19` 完全合法
> - `=` 不是数学的"等于",是**赋值**:右边算出结果,存进左边
> - 名字要**见名知意**,`name` 比 `a` 好;大小写敏感,`name` 和 `Name` 是两个变量

```python
name = "小明"
age = 18
height = 1.75
is_student = True

print(name)    # 使用变量时,不加引号!
print(age)
```

### 为什么数据要分类型?

先看一个"魔术":

```python
print(18 + 2)      # 20  —— 数字加数字:算术
print("18" + "2")  # 182 —— 文字加文字:拼接!
```

同样是 `+`,结果完全不同——因为 Python 是**按类型**决定怎么处理的。

> 📘 **概念卡 · 数据类型**
>
> **是什么**:数据的"种类"。本课认识四种:
>
> | 类型 | 名字 | 例子 | 用途 |
> | ---- | ---- | ---- | ---- |
> | `str` | 字符串 | `"小明"` | 一段文字 |
> | `int` | 整数 | `18` | 数数、年龄 |
> | `float` | 小数 | `1.75` | 身高、价格 |
> | `bool` | 布尔 | `True` / `False` | 只有"真/假"两种,做判断用(第 2 课的主角) |
>
> **为什么需要**:计算机存储和运算不同数据的方式不同。`18` 是"数量",能做算术;`"18"` 是"文字",只能拼接展示。类型就是 Python 选择处理方式的依据。
>
> **特性**:任何数据都能用 `type()` 查类型;**`"18"` 和 `18` 是两个世界的东西,引号就是分界线**。

```python
type("小明")    # <class 'str'>
type(18)        # <class 'int'>
type(1.75)      # <class 'float'>
type(True)      # <class 'bool'>
```

### 现场演示三大新手错误(重点!)

```python
print("你好")     # ✅ 英文引号
print(“你好”)     # ❌ 中文引号 → SyntaxError(引号是英文符号,中文的“”不认识)
print(hello)      # ❌ 没加引号也不存在变量 hello → NameError
print(Name)       # ❌ 大小写敏感,name ≠ Name → NameError
```

> **读报错三步法**:看最后一行错误类型 → 看行号 → 看箭头指向的位置。红字不可怕,它是计算机在告诉你哪里错了。

## 环节 ④:input——让程序开口"问"你(10 min)

```python
name = input("请输入你的名字:")
print(f"你好,{name}!")
```

```python
age = input("请输入年龄:")   # 输入 18,但 age 是 "18"(字符串)
print(age + 1)               # ❌ TypeError!
print(int(age) + 1)          # ✅ 19
```

> 📘 **概念卡 · input 为什么返回字符串**
>
> **是什么**:`input(提示语)` 在屏幕上显示提示语,等你敲字回车,**把你输入的内容作为字符串交还给你**。
>
> **为什么是字符串(而不是数字)**:程序运行前没法预知你会输入什么——可能敲数字、可能敲名字、也可能敲乱码。键盘本身只能敲出**字符**,所以 Python 统一按文本接收,这是最稳妥的设计。想当数字用?你自己负责"翻译"。
>
> **特性 / 配套工具**——类型转换函数:
>
> ```python
> int("18")     # 文字 "18" → 数字 18
> float("1.75") # 文字 → 小数
> str(18)       # 数字 → 文字 "18"
> ```
>
> 转换失败会报 `ValueError`(比如 `int("abc")`),因为"abc"实在翻译不成数字。

## 环节 ⑤:运算符与 f-string(15 min)

### 数字运算

```python
print(7 + 3)    # 10        加
print(7 - 3)    # 4         减
print(7 * 3)    # 21        乘
print(7 / 3)    # 2.333...  除(结果永远是 float 小数)
print(7 // 3)   # 2         整除:只要整数部分
print(7 % 3)    # 1         取余数:7 除以 3 余 1
print(2 ** 10)  # 1024      幂(平方、立方都用它)
```

**为什么要有 `//` 和 `%`**(不是为了刁难人):

- `//` 整除:100 个学生每页显示 10 个,要几页?`100 // 10 = 10`
- `%` 取余:判断奇偶(`18 % 2 == 0` 就是偶数)、周期规律(每 7 天一周)

### 字符串也能"运算"(呼应概念卡)

```python
print("哈" * 10)        # 哈哈哈哈哈…(重复 10 次)
print("你好" + "世界")   # 你好世界(拼接,还记得 "18"+"2"="182" 吗)
```

### f-string:把一切放进句子里

回忆两个麻烦:`"18" + 2` 报 TypeError;`"我今年 " + str(18) + " 岁"` 能跑但写得难受。**f-string 就是为了解决"把各种类型拼进一句话"而生的**:

```python
name = "小明"
age = 18
print(f"你好,{name},明年你 {age + 1} 岁")
# 你好,小明,明年你 19 岁
```

> 📘 **概念卡 · f-string(格式化字符串)**
>
> **是什么**:引号前加 `f`,`{}` 里的内容会被**求值后自动转成文字**嵌进句子。
>
> **为什么需要**:类型不同不能直接 `+`,f-string 让数字、文字随便混放,一行搞定。
>
> **特性**:
> - `{}` 里可以放**表达式**,不止变量:`{age + 1}`、`{len(name)}`
> - `{bmi:.1f}` 能控制保留 1 位小数(本课作业就会用到)

## 附录:课堂常见报错速查表

| 报错 | 常见原因 | 解决 |
| ---- | -------- | ---- |
| `SyntaxError: unterminated string literal` | 引号没闭合,或用了中文引号 `“”` | 全部换成英文引号 `"` |
| `NameError: name 'xxx' is not defined` | 变量名拼错 / 未定义 / 大小写不对 | 对照定义处的拼写 |
| `TypeError: can only concatenate str...` | 字符串和数字直接 `+` | 用 f-string,或 `str()` 转换 |
| `ValueError: invalid literal for int()` | `int("abc")` 这类非法转换 | 检查输入内容 |
| 缩进报错 `IndentationError` | 行首多了/少了空格 | 删掉行首空格,顶格写 |
